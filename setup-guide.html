Οδηγός εγκατάστασης Greek IPTV

Βήμα-βήμα οδηγίες εγκατάστασης Greek IPTV για κάθε συσκευή. Η εγκατάσταση διαρκεί λίγα λεπτά. Αν κολλήσετε, στείλτε μας μήνυμα στο WhatsApp.

Πριν ξεκινήσετε: Μετά την πληρωμή θα λάβετε στο email σας τα στοιχεία σύνδεσης: username, password και URL (ή M3U link / portal για MAG). Χρειάζεστε σύνδεση internet τουλάχιστον 15 Mbps. Για την καλύτερη εικόνα προτιμήστε καλώδιο Ethernet αντί για Wi-Fi.

Samsung & LG Smart TV

Κατεβάστε την εφαρμογή IPTV Smarters Pro από το κατάστημα εφαρμογών της τηλεόρασής σας.

Samsung

  1. Πατήστε το κουμπί Smart Hub στο τηλεχειριστήριο.
  2. Αναζητήστε IPTV Smarters Pro και εγκαταστήστε την.
  3. Ανοίξτε την εφαρμογή και συνδεθείτε με το username, το password και το URL που σας στείλαμε.

LG

  1. Πατήστε Home στο τηλεχειριστήριο και ανοίξτε το LG Content Store.
  2. Αναζητήστε IPTV Smarters Pro και εγκαταστήστε την.
  3. Ανοίξτε την εφαρμογή και συνδεθείτε με το username, το password και το URL που σας στείλαμε.
Amazon Fire TV Stick
  1. Εγκαταστήστε και ανοίξτε την εφαρμογή Downloader από το Amazon Appstore.
  2. Πληκτρολογήστε τον κωδικό 78522 και πατήστε Go.
  3. Θα ξεκινήσει η λήψη της εφαρμογής IPTV Smarters Pro. Όταν ολοκληρωθεί, πατήστε Install.
  4. Ανοίξτε την εφαρμογή, επιλέξτε Login with Xtream Codes API και εισάγετε username, password και URL.
  5. Καλή θέαση!

Αν το Downloader δεν επιτρέπει την εγκατάσταση, ενεργοποιήστε το Install unknown apps για το Downloader στις Ρυθμίσεις > My Fire TV > Developer options.

Android (κινητό, tablet, Android TV box)
  1. Ανοίξτε το Google Play Store.
  2. Αναζητήστε XCIPTV Player και πατήστε Εγκατάσταση.
  3. Ανοίξτε την εφαρμογή.
  4. Εισάγετε τα στοιχεία σύνδεσης που σας στείλαμε και πατήστε Login.
  5. Έτοιμο!
iPhone, iPad & Apple TV
  1. Κατεβάστε την εφαρμογή Smarters Player Lite από το App Store, ή αναζητήστε τη στο App Store.
  2. Ανοίξτε την εφαρμογή και επιλέξτε σύνδεση με Xtream Codes API.
  3. Εισάγετε τα στοιχεία σύνδεσης που σας στείλαμε και πατήστε ADD USER.
  4. Περιμένετε λίγα δευτερόλεπτα να φορτώσει η λίστα.
  5. Πατήστε Live TV και επιλέξτε την ομάδα καναλιών που θέλετε.
  6. Επιλέξτε ένα κανάλι και πατήστε δύο φορές τη μικρή οθόνη για πλήρη οθόνη.
MAG Box (250 / 254 / 256 …)

Για την ενεργοποίηση σε MAG, στείλτε μας μαζί με την παραγγελία τη MAC διεύθυνση που βρίσκεται στην ετικέτα στο πίσω μέρος της συσκευής. Η ενεργοποίηση γίνεται απομακρυσμένα και μετά σας στέλνουμε το URL του portal.

  1. Όταν εμφανιστεί η κεντρική οθόνη, μπείτε στις Settings και πατήστε SETUP/SET στο τηλεχειριστήριο.
  2. Επιλέξτε System Settings και μετά Servers.
  3. Επιλέξτε Portals.
  4. Στο Portal 1 Name γράψτε ένα όνομα και στο Portal 1 URL το URL που σας στείλαμε.
  5. Πατήστε OK για αποθήκευση.
  6. Πατήστε EXIT στο τηλεχειριστήριο.
  7. Επανεκκινήστε τη συσκευή πατώντας OK.
Windows & Mac
  1. Ανοίξτε τον ιστότοπο iptvsmarters.com και επιλέξτε Downloads.
  2. Κατεβάστε την τελευταία έκδοση του IPTV Smarters Pro για Windows ή macOS.
  3. Ανοίξτε το αρχείο που κατεβάσατε. Αν τα Windows ζητήσουν άδεια, επιλέξτε Ναι.
  4. Η εγκατάσταση διαρκεί ένα με δύο λεπτά.
  5. Ανοίξτε το πρόγραμμα, πατήστε Add new user και επιλέξτε Login with Xtream Codes API.
  6. Εισάγετε τα στοιχεία σας και ξεκινήστε!
Enigma2 / Linux δέκτες
  1. Στον δέκτη, μεταβείτε στο Settings > Setup > System > Network Device > Setup Adapter > Settings και σημειώστε τη διεύθυνση IP (ξεκινά με 192.168…).
  2. Στον υπολογιστή σας κατεβάστε και ανοίξτε το PuTTY.
  3. Εισάγετε την IP του δέκτη, θύρα 23, και πατήστε Open.
  4. Συνδεθείτε με username και password root.
  5. Επικολλήστε την εντολή που θα σας στείλουμε μετά την παραγγελία. Μοιάζει με αυτή:
wget -O /etc/enigma2/iptv.sh "ΤΟ_M3U_LINK_ΣΑΣ" && chmod 777 /etc/enigma2/iptv.sh && /etc/enigma2/iptv.sh
  1. Κάντε δεξί κλικ για επικόλληση και πατήστε Enter.
  2. Γράψτε reboot για επανεκκίνηση του δέκτη.
Προβλήματα & λύσεις

Η εικόνα κολλάει (buffering)

  1. Επανεκκινήστε το router και τη συσκευή σας.
  2. Συνδέστε τη συσκευή με καλώδιο Ethernet ή φέρτε την πιο κοντά στο router.
  3. Κλείστε άλλες εφαρμογές ή downloads που χρησιμοποιούν το internet.
  4. Ελέγξτε την ταχύτητά σας στο fast.com. Χρειάζεστε τουλάχιστον 15 Mbps.
  5. Στις ρυθμίσεις της εφαρμογής δοκιμάστε άλλον player (π.χ. «VLC» ή «Native»).

Η εφαρμογή δεν συνδέεται

  1. Ελέγξτε ότι username, password και URL είναι γραμμένα ακριβώς όπως στο email, χωρίς κενά.
  2. Βεβαιωθείτε ότι η συνδρομή σας δεν έχει λήξει.
  3. Μην είστε συνδεδεμένοι σε περισσότερες συσκευές από όσες επιτρέπει το πακέτο σας.

Αν το πρόβλημα συνεχίζεται, στείλτε μας στιγμιότυπο οθόνης του σφάλματος στο WhatsApp ή στο email.
